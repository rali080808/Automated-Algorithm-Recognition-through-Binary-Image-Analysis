In the field of computer security, the algorithm recognition used in a piece of software is
essential for analyzing its functionality and its potential maliciousness. This process is
particularly important when working with executable files where the source code is not
accessible and the analysis is based exclusively on the machine code. Traditional binary
analysis methods often rely on manual feature extraction and matching against known
patterns, which is labor-intensive and not always effective when dealing with new or complex
threats.
This project proposes an innovative approach to identify algorithms using Convolutional
Neural Networks (CNNs) commonly applied in image recognition. The basic idea is to
convert the binary code of the software into a two-dimensional image where the structure and
instruction sequences can be visualized as pixels. This method allows the CNN to analyze
the binary code in a manner similar to how objects are recognized in images, extracting key
features and patterns that can be associated with specific algorithms or malicious behaviors.
This approach is particularly useful in the context of cybersecurity, where there is a need
to detect and analyze malware as well as understand the behavior of unknown executables.
In addition, the method can be applied in other areas such as software reengineering, code
optimization and even in academic research to understand how different algorithms are
implemented in practice.
The project not only offers a new way to analyze binaries, but also demonstrates the potential
of deep learning to solve complex problems in computer security. By combining techniques
from the fields of computer vision and software analysis, this method can become a powerful
tool in the arsenal of security professionals, allowing them to tackle the increasingly complex
and diverse threats in the digital world.
